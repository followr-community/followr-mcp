## Bugs encontrados durante el preflight

### BUG-001: Creative Studio endpoint rechaza content_type valido

**Endpoint**: POST /api/companies/{id}/creative
**MCP tool**: generate_brand_creative
**Schema docs**: content_type acepta `"single" | "carousel" | "auto"`
**Comportamiento observado**: el backend devuelve
`{"error": "The selected content type is invalid."}` para los tres valores
del enum, en multiples companies (id 42129 PipeLime, id 7 Followr for MCP).

**Impacto**: el path de Creative Studio que documenta v0.6.1 (Paths A y B del
Tier 1 routing) no es invocable hoy. La generacion de Tier 1 cae al endpoint
legacy /api/aiResults/image que NO aplica brand enrichment.

**Lo que no se sabe sin acceso al backend**:
- Si el nombre del campo cambio (puede ser content_type renombrado a
  `creative_type`, `type`, `mode`, etc.)
- Si el value space cambio (single -> image, carousel -> ?)
- Si content_type fue removido y otro campo lo reemplazo
- Si validacion espera content_type + algo mas (el error original decia
  "and 1 more error", sugiriendo un segundo campo invalido)

**Accion recomendada**: revisar el codigo del backend para
`/api/companies/{id}/creative` y alinear el MCP schema. Es un blocker para
shipear v0.6.1 a produccion porque Tier 1 sin Creative Studio enrichment
pierde la mitad del valor (brand identity + design system + style_key).
